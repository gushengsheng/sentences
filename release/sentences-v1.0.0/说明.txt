【怎么启动】
双击「启动游戏.cmd」。
窗口里会显示两个地址：
  本机:  http://127.0.0.1:4173/
  手机:  http://<本机局域网IP>:4173/
在浏览器里打开即可。关闭窗口就停止。

需要 Node.js（你电脑上已经有）。

【为什么不能直接双击 index.html】
这是一个前端应用，浏览器出于安全限制，不允许从 file:// 
直接加载 ES 模块。必须通过 http:// 访问。

【手机怎么连】
1. 手机和电脑连同一个 Wi-Fi
2. 在电脑上查局域网 IP：
   Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*' }
3. 手机浏览器打开 http://<那个IP>:4173/

【内容】
index.html          入口
assets/             打包后的 JS 和 CSS
maps/               地图包（3 个战役，共 10 个战区）
serve.mjs           自带的小型静态服务器
启动游戏.cmd         双击启动

【换端口】
如果 4173 被占用，可以在命令行里设置环境变量再启动：
  set PORT=5000
  node serve.mjs
