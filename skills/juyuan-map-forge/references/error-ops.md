# 错误算子表

这张表同时是**生成指令**和**复盘分类**。生成时从里面选 4 个互不相同的算子。

| 算子 `errorOp` | 做法 | 例子（原文 → 篡改） | 难度 |
|---|---|---|---|
| `number` | 改数字或量级 | 含糖量 20%–40% → 2%–4% | 中 |
| `name` | 换专名 | 工蜂 → 雄蜂 | 低 |
| `negation` | 加/去否定 | 能看见紫外线 → 看不见紫外线 | 低 |
| `causal` | 因果倒置 | 因为 A 所以 B → 因为 B 所以 A | 高 |
| `condition` | 条件偷换 | 只要 → 只有 | 高 |
| `scope` | 范围/程度改变 | 所有 → 部分；必须 → 可以 | 中 |
| `time` | 时间/顺序改变 | 已经 → 将要；先 → 后 | 中 |
| `subject-object` | 主客颠倒 | A 影响 B → B 影响 A | 高 |
| `wording` | 近义词偏移 | 抑制 → 促进 | 中 |

## 使用规则

1. **一个句元内，4 个篡改项必须用 4 个不同算子。**
2. 优先选该句“承载信息量最大”的要素。带数字的句子优先 `number`。
3. 难度梯度：初级多用 `name` / `negation` / `number`，高级多用 `causal` / `condition` / `subject-object`。
4. 生成后给每个篡改项标上 `errorOp`，写进报告，供以后做错题本。

## 反例

- ❌ 同时改两处（“工蜂是雄性，寿命三十天”）——不是单点，玩家无法定位。
- ❌ 改成荒谬命题（“蜜蜂是鸟类”）——只是常识题。
- ❌ 用生僻词制造差异——考的是词汇量，不是理解。
- ❌ 长度明显不同——玩家可以靠长短排除。
