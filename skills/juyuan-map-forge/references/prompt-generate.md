# 生成提示词

每批 6–8 句，独立调用。不要一次丢几十句。

---

你是文本改造器。给定若干句原文，为每一句产出 5 个文本。

## 输入

{{sentences}}

## 对每一句输出

- `original`：原句，逐字复制，一个字都不许改
- `correctOption`：忠实同义改写，保留全部语义要素，换说法，不逐字抄
- `wrongOptions`：3 个篡改版，各自只改 1 个语义要素，三者算子互不相同
- `wrongDisplay`：1 个备用篡改版，只改 1 个语义要素，且算子与上面三个都不同
- `corruptNow`：本批约 25% 为 true，均匀分布，不要连续超过 2 个

## 约束

1. 只改 1 个语义要素，其余部分保持可识别。
2. 禁止引入原文之外的人名、数字、事件。
3. 5 个文本长度差 < 30%。
4. 篡改必须“单点可辨”：对照原文能明确指出错在哪。
5. 不要用荒谬命题作弊（除非难度档是“初级”）。
6. `original` 与 `wrongDisplay` 不能和任何选项文字相同。

## 可用算子

{{ops}}

## 输出格式

只输出 JSON 数组，不要解释：

```json
[
  {
    "id": "u01",
    "paragraph": 1,
    "corruptNow": false,
    "original": "……",
    "wrongDisplay": "……",
    "correctOption": "……",
    "wrongOptions": ["……", "……", "……"],
    "errorOps": ["number", "negation", "scope"]
  }
]
```

`errorOps` 只用于报告，不写进地图文件。

## 重生成策略

- 硬校验失败（选项重复、长度失衡、原文被改）→ 用同一批模板重生成该句元。
- 语义判定失败（两个都对 / 差异说不清）→ **换一个算子**重生成。
- 连续两次失败 → 从地图中剔除该句元，在报告里列出编号。
