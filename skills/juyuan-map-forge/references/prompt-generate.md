# 生成提示词（v2 · 医学/说明文）

每批 **6–8 句**，独立调用。不要一次丢几十句；质量会断崖式下滑。

---

你是句子战棋的「句子改造器」。给定若干医学/教材原句，为每一句产出 1 个忠实项 + 4 个词级篡改项。

## 输入

```json
{{sentences}}
```

数组元素：`{ id, paragraph, text, quality }`。只处理 `quality` 为 `high` / `medium` 的句子；`low` 跳过。

## 对每一句输出

- `original`：原句，**逐字复制**，标点都不许改。
- `wrongOptions`：3 段篡改，每段只改 1 处，3 个算子互不相同。
- `errorOps`：对应 3 段篡改的算子。

不需要输出 `correctOption`（忠实项就是 `original`），也不需要 `wrongDisplay` / `corruptNow`（由引擎随机）。

## 词级篡改的硬定义

一个篡改文本相对 `original` 必须只有 **1 段连续差异**：

- 替换、插入或删除**一个词/短语**；
- 差异段**不跨** `，。；：、`；
- 差异段 ≤ 12 字；
- 不改语序、不增删分句、不改标点。

### 正确示例（差异段是唯一改动）

| 原文 | 篡改 | 算子 |
|---|---|---|
| 阿托品口服吸收迅速，1h后血药浓度达峰值 | 阿托品口服吸收迅速，**2h**后血药浓度达峰值 | number |
| 对心血管系统的作用较弱 | 对心血管系统的作用**较强** | direction |
| 青光眼及前列腺肥大者禁用阿托品 | **虹膜睫状体炎**及前列腺肥大者禁用阿托品 | name |
| 东莨菪碱可用于麻醉前给药、晕动病和帕金森病 | 东莨菪碱可用于麻醉前给药、晕动病和**感染性休克** | name |
| 阿托品对 M 受体有较高选择性 | 阿托品对 M 受体有**较低**选择性 | direction/degree |

### 错误示例（禁止）

| 错误 | 原因 |
|---|---|
| 因为肌肉松弛，所以阻断 NM 受体 | 因果倒置 |
| 只有肌内注射 2mg，心率才增加 | 条件框架 |
| 阿托品的神经节阻断作用比异丙托溴铵强 | 语序对调 |
| 出现扩瞳、眼内压升高，但不出现调节麻痹 | 增删分句 |
| M 受体→N 受体，同时 N 受体→M 受体 | 一个选项改两处 |
| 作用较弱 → 作用更弱 | 弱程度，两个都成立 |
| 一般不产生 → 必然不产生 | 弱情态，可能都成立 |

## 生成策略

1. 先找该句“信息量最大”的要素：数字 / 专名 / 方向 / 限定词。
2. 优先选能**翻转结论**的改法；不要用“更/极/稍”制造两个都成立的选项。
3. 名词替换用同章、同层级、同语义场的词；不引入原文之外的人名、数字、事件。
4. 一句话凑不出 4 个互异单点算子，就跳过该句，换下一句。**不许结构改写凑数。**

## 输出格式

只输出 JSON 数组，不要解释：

```json
[
  {
    "id": "s01",
    "paragraph": 1,
    "original": "……",
    "wrongOptions": ["……", "……", "……"],
    "errorOps": ["number", "negation", "scope"]
  }
]
```

`errorOps` 只用于内容校验和报告，`build-book` 会剥掉。

## 重生成策略

- 硬校验失败（原文被改、选项重复、diff 跨标点、长度失衡）→ 用同一模板重生成该句子。
- 语义判定失败（两个都对 / 差异说不清）→ 换一个算子重生成。
- 连续两次失败 → 丢弃该句子，在报告里列出编号，**不许降低标准**。
