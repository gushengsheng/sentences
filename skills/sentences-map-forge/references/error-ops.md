# 词级篡改算子表（医学/说明文）

这张表既是生成指令，也是复盘分类。**只允许词级替换，禁止结构改写。**

## 允许的 14 个算子

| 算子 `errorOp` | 做法 | 原文 → 篡改 | 注意 |
|---|---|---|---|
| `scope` | 限定/范围 | 只→都；某些→所有；多→均；可→必须 | 改变覆盖范围 |
| `negation` | 判断/否定 | 是→不是；有→没有；能→不能；属于→不属于 | 加/去否定词 |
| `number` | 数字/量级 | 20~30→30~40；50%→70%；1h→2h | 只改一段数字，单位不动 |
| `name` | 名词/专名 | 阿托品→东莨菪碱；M→N；虹膜→睫状肌；青光眼→虹膜睫状体炎 | 同章、同层级、同语义场 |
| `direction` | 方向/极性 | 促进↔抑制；升高↔降低；松弛↔收缩；缩短↔延长 | 反义方向，最稳 |
| `subject-object` | 主客/语态 | 影响→被影响；抑制→被抑制 | **只加“被/受”，不换语序** |
| `time` | 时间/顺序 | 已→将；早期→晚期；先→后；短时→持久 | 不改事件本身 |
| `degree` | 程度/频率 | 明显→轻微；远大于→略大于；常见→罕见 | **必须翻转结论**，不能“小→极小” |
| `modality` | 情态/确定性 | 可→必须；可能→一定；建议→禁止 | **必须改变许可/义务/确定性**，不能只是语气强弱 |
| `unit` | 单位/符号 | mg→μg；%→‰；小时→天 | 保留数值格式 |
| `population` | 人群/年龄 | 儿童→成人；青壮年→老年人；男性→女性 | 人群层级要可比 |
| `route` | 给药途径 | 口服→静脉注射；肌内→皮下；气雾→口服 | 只换途径 |
| `position` | 部位/侧别 | 下壁→前壁；左→右；近端→远端；上→下 | 解剖部位要同类 |
| `comparator` | 比较词 | 大于→小于；强于→弱于；高于→低于；多于→少于 | 只换比较方向 |

## 禁止的做法

- `causal`：因果倒置（A 因为 B → B 因为 A）——必然动语序。
- `condition`：加“只有…才 / 如果…就 / 只要…就”——改句式。
- `wording`：近义词偏移（抑制→促进之外的模糊替换）——容易“两个都说得通”，改走 `direction` / `name`。

## 一个句子内的规则

1. `wrongOptions` 恰好 3 段，**3 个算子互不相同**。
2. 每个篡改相对 `original` 只有 **1 段连续差异**：
   - 替换、插入或删除一个词/短语；
   - 差异段不跨 `，。；：、`；
   - 差异段 ≤ 12 字。
3. **一个选项只改一处**。禁止成对替换（如 M→N 的同时把另一处 N→M）。
4. `original` 逐字复制，它就是四选一里的忠实项。
5. 4 段文本（`original` + 3 段篡改）两两不同。
6. 4 段文本长度比 ≤ 1.3。

## 反例

- ❌ 同时改两处：“工蜂是雄性，寿命三十天。”
- ❌ 因果倒置：“因为肌肉松弛，所以阻断 NM 受体。”
- ❌ 条件框架：“只有肌内注射 2mg，心率才可增加。”
- ❌ 语序对调：“阿托品的神经节阻断作用比异丙托溴铵强。”
- ❌ 改标点/拆句：“…；因此…” → “…。因此…”
- ❌ 弱程度：“作用较弱”→“作用更弱”（两个都成立）。
- ❌ 弱情态：“一般不产生”→“必然不产生”（可能都成立）。
- ❌ 荒谬命题：“阿托品是抗生素。”
- ❌ 引入原文之外的人名、数字、事件。

## 医学类词库建议

- 药名：同章同类药互换（阿托品 / 东莨菪碱 / 山莨菪碱 / 樟柳碱；后马托品 / 托吡卡胺；哌仑西平 / 替仑西平）。
- 受体：M↔N；M1↔M2↔M3；NN↔NM。
- 解剖：虹膜↔睫状肌；瞳孔括约肌↔瞳孔开大肌；运动终板↔神经节；呼吸道↔消化道。
- 疾病/症状：青光眼↔虹膜睫状体炎；心动过缓↔心动过速；感染性休克↔晕动病。
- 剂量/数字：0.4~0.6mg、2mg、5mg、10mg；10%~30%、50%；2~3天、1~2周。
- 途径：口服↔静脉注射↔肌内注射↔气雾吸入↔滴眼。
- 人群：儿童↔成人↔青壮年↔老年人。
